# Grilling

Stress-test designs and develop ideas with human expertise before handing off implementation.

## What it does

Interviews you about a plan, challenges assumptions, and develops ideas from your experience.
Questions include the context needed to understand difficult decisions.

## When to use

Use before starting a project or feature, or to explore an unfinished research idea.
It ends with shared understanding and acceptance criteria for delegated work.

## Install

```bash
npx skills add HelmholtzAI-Consultants-Munich/helmholtz-agent-skills --skill grilling
```

## Install in Claude Science

**Skills → Add skill → Import from GitHub**, then paste:

```
https://github.com/HelmholtzAI-Consultants-Munich/helmholtz-agent-skills
```

Select `method-skills`. [Walkthrough](../claude-science.md).

## Replacing an earlier installation

Remove the former external grilling plugin or skill, then install this version through
`method-skills` or the command above. Keep one active grilling definition.
